# L4 行业成品页与 Prompt 分类设计

## 目标

把 NAS `motionsites_661/prompts/` 当前实际存在的 405 条 prompt 转成可检索的派生分类目录，并从中选择视觉差异明显的行业方向，在 L4 里展示真实、可滚动、可互动的成品页面。

用户此前已明确本项目后续无需逐项确认，本设计按同一任务连续执行。NAS 原始 prompt 只读，不修改、不外发。

## 事实边界

- NAS 路径当前有 405 个 `.md` 文件，不是 600+ 个。
- GitHub 原仓库当前因 DMCA 下架，不能作为缺失素材补齐来源。
- 本轮分类 405 条现有材料；分类器支持未来目录增加后重新生成。
- 不把 405 条 prompt 全部直接生成网页。全部分类，精选 6 个行业方向做成品页。

## 分类模型

每条 prompt 生成以下派生字段：

- `id`、`fileName`、`title`
- `industry`：科技 SaaS、金融、文旅酒店、汽车交通、消费零售、文化艺术、创意机构、教育、健康、地产建筑、餐饮、其他
- `pageType`：完整落地页、Hero、作品集、产品页、功能区块、定价、仪表盘、电商、活动页
- `style`：未来科技、编辑排版、奢华极简、自然沉浸、工业粗野、明亮友好、电影叙事、数据终端、3D 空间
- `engines`：CSS/DOM、Media、Canvas、Three/WebGL、Motion
- `signals`：分类命中的短关键词，不保存完整 prompt
- `sourcePath`：NAS 相对文件名

生成 `registry/motionsites-prompt-catalog.json` 和简短统计报告。无法明确判断的项目保留 `other`，不强行伪造行业。

## L4 成品页矩阵

首批 6 个方向：

| 行业 | 页面 | 视觉语言 | 核心互动 |
| --- | --- | --- | --- |
| AI 科技 | COGNITRA 自动化机构 | 冷灰编辑 + 视频叙事 | 滚动章节、服务揭示 |
| 金融财富 | ARAISE 财富顾问 | 黑金数据终端 | 指标卡、报价与章节滚动 |
| 文旅探索 | Aetheris Voyage | 黑色电影宇宙 | 视差、轨道、章节推进 |
| 消费潮玩 | TOONHUB 收藏品 | 高饱和玩具空间 | 拖拽轮播、磁性对象 |
| SaaS 商业 | Apex Revenue | 明亮转化型产品页 | 滚动揭示、数据证明 |
| 文化艺术 | Ink Pavilion | 宣纸红黑编辑 | 竖排题签、卷轴滚动、指针墨迹 |

每个成品页在 L4 中拥有：

- 实际页面 iframe，不再使用抽象配方缩略图；
- 同一个页面同时承担封面和进入后的预览；
- 激活后可在卡片内滚动；
- 独立打开/复制完整页面；
- 行业、风格、引擎和来源 prompt 标签。

其余 L4 项目继续保留微型长页配方，形成“精选成品页 + 全量配方”的两层结构。

## 实现路径

1. 增加可重跑的 prompt 分类器，输入外部 prompt 目录，输出派生 JSON。
2. 为分类器补充确定性测试：总数、必填字段、行业覆盖、未知项保留。
3. 将现有 5 个成品页纳入 L4。
4. 新增文化艺术成品页，使用纯 HTML/CSS/Canvas，确保单文件可嵌入。
5. 扩展 L4 schema 和渲染：`preview.mode = page`、`preview.page`。
6. 单 HTML 构建器嵌入全部精选成品页。
7. 桌面和 390px 手机验收：页面可见、卡内滚动、无横向溢出、无控制台错误。

## 验收

- 分类 JSON 等于 NAS 当前实际 prompt 数量 405。
- 至少覆盖 8 个行业、6 个页面类型、7 个风格方向。
- L4 至少有 6 个 `finished-page` 条目。
- 六个页面均在卡片封面中显示真实页面，并能激活后内部滚动。
- 单 HTML 中六个页面都以 `srcdoc` 运行，不依赖本地相对文件。
- 全量自动测试通过，主页面和单 HTML 完成桌面/手机浏览器检查。

## 回滚

删除分类产物和新增页面条目即可恢复到原有 24 个 L4 配方；NAS 原始资料不受影响。
